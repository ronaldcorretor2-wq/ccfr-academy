# Contexto do projeto (para futuras sessões)
- Produto: CCFR Academy, LMS cristão, multi-igreja. Primeira igreja: Comunidade Cristã Família e Reino.
- Stack: Next.js 14 (App Router) + TypeScript + Supabase (Auth, Postgres com RLS). Deploy: Netlify via GitHub.
- Decisão do dono: visual (cores preto e branco, fontes) fica para depois; prioridade é funcionar de ponta a ponta.
- Estado: Fase 2/3/4 em versão mínima (ver LEIA-ME.md). Próximos: editar/reordenar aulas, retomar vídeo, avaliações, certificados, trilhas, painel mestre, auditoria, testes de isolamento.
- Regras: papel e organização vêm do banco (RLS), nunca do navegador; org_id nas ações é derivado da sessão no servidor.
- Avaliações (migração 002): questionário por aula, correção no banco (função submit_attempt); gabarito em tabela só da equipe; aula com avaliação só conclui após aprovação.
- Retomar vídeo (YouTube IFrame API, posição salva a cada 10 s) e certificados (migração 003: emissão por função no banco, código verificável em /verificar/CÓDIGO).
- Anotações, favoritos, materiais (links), trilhas com pré-requisito (checado no servidor) e relatórios por curso (migração 004). Pendente: segurança (trancar criação de igrejas, auditoria), painel mestre, testes de isolamento, upload de arquivos (Storage), visual final.
- Segurança (migração 005): só o painel mestre cria igrejas (platform_admins), plano e limite de alunos, auditoria por gatilhos. Testes de isolamento: 006 (select * from run_isolation_tests()). Pendente: upload de arquivos (Storage), visual final, domínios.
- Envio de PDF/áudio e logotipo via Supabase Storage (migração 007, bucket privado materiais, caminho começa pelo id da igreja), visual final: fontes Schibsted/Hanken, tema claro/escuro, capas geométricas provisórias, hero no dashboard. Pendente: fotos reais das capas, domínios próprios, subdomínios.
